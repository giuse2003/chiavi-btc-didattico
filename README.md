# Generatore di chiavi private Bitcoin

Pagina web didattica per generare chiavi private Bitcoin sequenziali e mostrarle in formato WIF compresso.

## Caratteristiche

- Funziona aprendo `index.html` nel browser.
- Non interroga la blockchain.
- Non controlla saldi.
- Non invia dati online.
- Non usa API esterne.
- Non usa librerie da CDN.
- Non usa `localStorage`, cookie, `fetch`, `XMLHttpRequest` o `WebSocket`.

## Uso

1. Inserisci il numero iniziale.
2. Scegli quante chiavi generare, fino a un massimo di 20.000.
3. Premi `Genera`.
4. Usa `Avanti` e `Indietro` per navigare tra le pagine.
5. Usa `Copia CSV` o `Scarica CSV` per esportare solo le chiavi WIF.

## Avviso

Strumento didattico. Non usare per cercare wallet altrui. Non inserire o salvare chiavi private reali con fondi.

Le chiavi generate sono sequenziali e quindi non sono sicure per custodire Bitcoin.
